# OfficeWhere 실제 사례 테스트 라이브러리

앱에서 이 폴더를 문서 폴더로 추가한 뒤 문서 새로고침을 실행하세요.

## 검색 확인 키워드
- `A 프로젝트`: Word/PPT/TXT/MD 본문 검색 확인
- `예산 조정`: Excel v1.1과 부서B 회의록 본문 검색 확인
- `회의록`: 파일명 검색 확인

## 정합성 확인 시나리오
- `회의록.docx`: 부서A/부서B에 같은 파일명이지만 내용이 다른 문서
- `공통양식.xlsx`: 부서A/부서B에 같은 파일명이고 내용도 같은 문서
- `주간보고`, `프로젝트상태`, `사업예산`: v1 계열부터 v4까지 이어지는 버전 이력 문서
