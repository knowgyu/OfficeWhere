# OfficeWhere v0.6.4

Excel 전체 시트 지원 이후, 버전관리의 `표로 보기`에서 여러 시트가 세로로 이어져 보이던 흐름을 시트 선택형 UX로 정리한 패치입니다.

## 변경 사항

- Excel `표로 보기` 모달에서 변경 시트가 여러 개일 때 Excel처럼 시트 탭을 선택해 한 시트씩 확인할 수 있습니다.
- 시트를 바꾸면 선택된 셀 상세도 초기화되어 다른 시트의 셀 상세가 남아 보이지 않습니다.
- 현재 보고 있는 시트명이 상단 요약 칩과 셀 상세 위치에 함께 표시됩니다.
- 앱/백엔드 버전 메타데이터를 `0.6.4`로 올렸습니다.

## 메모

- AI Agent가 OfficeWhere의 검색/색인/버전 정보를 안전하게 사용할 수 있는 로컬 API 또는 MCP 표면은 다음 작업 후보로만 남겼습니다. 이번 릴리즈에는 포함하지 않았습니다.

## 테스트

- `./venv/bin/python -m pytest -q`
- `./venv/bin/python -m compileall backend backend_server.py -q`
