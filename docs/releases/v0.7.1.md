# OfficeWhere v0.7.1

## 요약

Excel 처리 엔진을 pandas/numpy 기반에서 OfficeWhere 전용 경량 XLSX 파서로 바꾼 용량/성능 최적화 릴리즈입니다. 사용자 문서는 계속 읽기 전용으로만 다루며, 지원 Excel 형식은 `.xlsx`로 단순화했습니다.

## 주요 변경

- Excel 색인, 검색 위치, 버전 비교, “표로 보기”가 `ExcelUsedRange` rows/cells 모델을 사용합니다.
- `.xlsx` 시트 XML을 직접 읽어 마지막 값이 있는 행/열, 검색 chunk, 셀 인덱스를 한 흐름에서 계산하도록 정리했습니다.
- `.xls` 지원을 제거했습니다. 등록/스캔/파일 선택/안내 문구의 지원 형식은 `.xlsx`, `.docx`, `.pptx`입니다.
- 기존 앱 DB에 남아 있을 수 있는 `.xls` 등록/색인 레코드는 시작 또는 새로고침 시 앱 소유 DB에서만 제거합니다. 원본 `.xls` 문서는 삭제하거나 수정하지 않습니다.
- 백엔드 런타임 의존성에서 `pandas`, `numpy`, `xlrd`, `openpyxl`, `xlsxwriter`와 관련 Excel 작성/분석용 패키지를 제거했습니다. `openpyxl`은 테스트/데모 생성용 개발 의존성으로만 유지합니다.
- Windows 번들 Python runtime의 site-packages에서도 제거 대상 패키지를 정리해 배포 zip 크기를 줄였습니다.
- 앱/백엔드 버전을 `0.7.1`로 올렸습니다.

## 검증

- Python backend tests, demo checks, compileall
- Frontend TypeScript/Vite build, Electron main/preload build
- pandas/numpy/xlrd 미사용 및 runtime package pruning 확인
- `.xls` 등록 거절 및 기존 DB 레코드 정리 회귀 테스트
