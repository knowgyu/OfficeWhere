# OfficeWhere v0.7.7

## 변경 사항

- GitHub Actions 릴리스 빌드에서 Windows x64 zip과 macOS arm64 dmg/zip 산출물을 함께 게시하도록 정리했습니다.
- macOS 런타임 준비 단계와 Electron 패키징 단계를 분리해, 패키징 도구가 GitHub Release 게시 작업을 직접 시도하지 않도록 했습니다.
- Electron Builder 설정은 산출물 생성 전용으로 고정하고, GitHub Release 업로드는 별도 workflow job에서만 수행합니다.
- macOS 패키지는 사용자 PC에 별도 개발 도구 설치가 없어도 실행되도록 앱 전용 backend runtime을 포함합니다.
- 다운로드/직접 빌드 문서에서 macOS 패키지를 더 이상 “추후 지원”으로 안내하지 않도록 정리했습니다.

## 참고

- Windows와 macOS 모두 앱 실행에 필요한 backend runtime을 패키지 안에 포함합니다.
- Linux packaged release는 아직 제공하지 않습니다.
