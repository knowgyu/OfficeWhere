# OfficeWhere v0.16.1

파일 이동 추적과 Electron 위치 권한 처리를 보강한 패치 릴리즈입니다.

## 변경 사항

- Electron의 `geolocation` 권한 요청과 확인을 명시적으로 거부합니다.
- 문서가 이동되거나 이름이 바뀌어도 내용 지문이 유일하게 일치하면 기존 파일 ID, 검색 색인, 비교 이력을 유지합니다.
- 기존 경로는 새 경로로 갱신하며, 원본 문서는 이동하거나 수정하지 않습니다.
- 등록 파일 목록의 단순 목록 새로고침과 실제 문서 새로고침을 UI에서 구분합니다.
