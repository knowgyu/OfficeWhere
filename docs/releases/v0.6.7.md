# OfficeWhere v0.6.7

## 요약

v0.6.6 이후 안정화된 아키텍처 보강 체크포인트입니다. 사용자 기능 동작은 유지하면서 CI 유지보수, 앱 데이터 초기화 후 재시작 UX, 보안/안전성 보강, 책임 경계 리팩터링을 정리했습니다.

## 주요 변경

- GitHub Actions 릴리즈 빌드 환경을 Node.js 24 계열과 최신 공식 액션으로 갱신했습니다.
- 앱 데이터 초기화 후 수동으로 여러 번 실행해야 하던 흐름을 줄이기 위해, 정리 성공 후 앱 재시작을 예약하도록 개선했습니다.
- Electron 외부 링크 열기는 HTTP/HTTPS만 허용하도록 제한했습니다.
- 파일 위치 열기 동작은 shell 문자열 실행 대신 안전한 인자 기반 서비스로 분리했습니다.
- DB 읽기 커넥션 관리, 비교 artifact 저장소, 리스캔 상태/설정 seam, 한글 검색 회귀 테스트를 보강했습니다.
- FileManager와 ConsistencyCheck의 일부 표시 책임을 presenter/section 컴포넌트로 분리했습니다.

## 검증

- v0.6.7 기준 코드 변경 전 단계에서 다음 검증이 통과했습니다: backend pytest 149개, demo checks, Python compileall, frontend build, Electron build, git diff check.
- 이 태그는 v0.6.6 이후 아키텍처 보강 완료 지점을 표시합니다.
