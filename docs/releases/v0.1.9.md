# OfficeWhere v0.1.9 Release Notes

## Highlights

- Word version changes now use the same side-by-side style as PPT:
  - **기존 내용** and **변경 후 내용** panels replace the git-style `-` / `+` rows.
  - Word changes show a best-effort page label such as `2쪽` when page-break/rendered-page-break data is available in the DOCX.
- Added version-management view-size controls:
  - `기본`, `크게`, `더 크게` buttons in the Version Management screen.
  - `Ctrl +`, `Ctrl -`, `Ctrl + mouse wheel`, and `Ctrl + 0` work while the screen is open.
- Excel differences now separate single-cell value changes from broader table-structure changes:
  - `값 다름` remains for clear cell-level differences.
  - row-only/column-only differences are grouped as `표 구조 차이` because they can reflect layout/transpose/schema drift rather than a simple feature addition.

## Notes

DOCX does not store fully stable page numbers like a PDF. Word page labels are based on explicit page breaks and Word's saved rendered-page-break markers, so they should be treated as a practical locator rather than a guaranteed print-layout page number.

## Verification

- Backend test suite: `./venv/bin/python -m pytest`
- Frontend build: `cd frontend && npm run build`
- Static checks: `git diff --check`, `./venv/bin/python -m compileall -q backend`
