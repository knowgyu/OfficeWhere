# OfficeWhere v0.1.7 Release Notes

## Highlights

- Reworked the consistency screen into a user-facing **Document History** experience.
- Version groups now calculate detailed adjacent diffs only when a user opens a specific group, avoiding heavy upfront work on large libraries.
- Word changes are shown with familiar red deletion / green addition diff styling.
- Excel history details now identify changed cells by row and column, for example `23행 D열 (D23)`.
- PowerPoint history keeps slide numbers visible for added/deleted/changed slide evidence.
- Simplified Settings by removing the one-off folder scan flow and keeping the safer target-folder registration flow plus individual file add.
- Clarified that mapped/network folders are read by path only; OfficeWhere does not modify source documents.

## Repository cleanup

- Removed internal planning/architecture scratch documents from the tracked GitHub repository. They remain ignored locally by `.gitignore`.
- Kept end-user and release-facing docs under `README.md` and `docs/`.

## Verification

- Backend test suite: `./venv/bin/python -m pytest`
- Frontend build: `cd frontend && npm run build`
- Static checks: `git diff --check`, `./venv/bin/python -m compileall -q backend`
