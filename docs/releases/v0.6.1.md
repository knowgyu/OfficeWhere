# OfficeWhere v0.6.1

검색 결과와 버전관리에서 체감 마찰을 줄이는 패치 태그입니다. 이 태그는 GitHub Release를 즉시 publish하지 않고, 검증된 커밋을 원격에 고정하기 위한 태그입니다.

## 변경 사항

- 검색 결과에서 `더 보기`를 눌러 추가 파일을 불러와도 이미 열어둔 `본문 매칭` 섹션이 유지됩니다.
- 버전관리에서 별표로 `최신 파일`을 지정하거나 자동 정렬로 되돌릴 때, 비교 이력 재계산을 기다리지 않고 UI가 먼저 반응합니다.
- backend는 최신 파일 지정 응답을 warm group cache 기반으로 반환해 불필요한 즉시 전체 그룹 재구성을 줄입니다.
- 다음 성능 작업을 위해 `docs/version-management-first-load-plan.md`에 RALPLAN 계획을 남겼습니다.
- 태그 push만으로 GitHub Release가 만들어지지 않도록 release workflow를 조정했습니다. Release publish는 수동 `workflow_dispatch`에서만 수행합니다.

## 테스트

- `./venv/bin/python -m pytest -q`
- `cd frontend && npm run build`
- `cd frontend && npm run build:electron`
- `./venv/bin/python scripts/run_demo_checks.py`
- `./venv/bin/python -m compileall backend backend_server.py -q`
- `git diff --check`
