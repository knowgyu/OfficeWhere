# OfficeWhere v0.7.14

## 달라진 점

- 검색 탭을 처음 열 때 이미 대상 폴더가 등록되어 있으면 `대상 폴더 추가` 대신 `검색 대상 확인`으로 안내하도록 정리했습니다.
- 검색어를 입력하기 전에도 최근 준비된 문서를 가볍게 보여 주어, 바로 열거나 폴더를 확인할 수 있게 했습니다.
- 등록된 폴더는 있지만 아직 색인된 문서가 없을 때는 폴더를 다시 추가하라고 하지 않고 새로고침/색인 상태를 확인하도록 안내합니다.
- 릴리즈 Actions에 중복 실행 취소, `actions/cache@v5`, 이미 압축된 산출물의 재압축 생략을 적용했습니다.
- 프론트엔드 테스트 Actions도 lockfile 기반 `node_modules` 캐시를 공유해 캐시 적중 시 반복 `npm ci`를 건너뛰도록 했습니다.

## 확인한 항목

## 참고

- Windows와 macOS 릴리즈 산출물은 GitHub Actions 태그 빌드에서 생성·게시됩니다.
- Linux packaged release는 아직 제공하지 않습니다.
