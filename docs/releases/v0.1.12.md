# OfficeWhere v0.1.12

## Changed

- Version Management Excel comparisons now use the actual worksheet area for version history instead of the saved Excel-integration parser range.
- Stale Excel registration ranges no longer surface `parser_config ... 범위가 시트 크기를 벗어났습니다` in Version Management history or `표로 보기`.
- Excel `표로 보기` now opens from the latest sheet used range and keeps source row/column coordinates.
- The automatically detected Version Management list stays in a single column even on wide screens.
- Version group cards remove noisy detection copy and `최신 후보` / `이전 후보` wording; version/date tokens are shown more directly.
- Excel Integration now shows a top warning that the feature is still under active development.
- README is rewritten around user-facing `사용 시나리오` instead of a broad feature list.

## Verification

## Notes

- Manual Excel consistency checks and Excel Integration still use the registered table/key-column flow.
- Version Management's Excel view is comparison-oriented and does not try to reproduce Excel formatting pixel-perfectly.
