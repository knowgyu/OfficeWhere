# OfficeWhere v0.14.0 release notes

## Faster startup and refresh behavior

- Startup no longer performs large SQLite cleanup/index-version scans on the backend health path. Heavy repair work is deferred to the background indexer so Electron does not time out just because the local DB has grown.
- Unsupported-extension pruning is versioned and runs as background maintenance instead of blocking app launch.
- File-search hide actions now filter the already loaded result list locally instead of immediately re-querying the backend.

## Everything SDK DLL bundling

- Windows x64 releases now include `Everything64.dll` under the backend vendor resource path so OfficeWhere can find the Everything SDK client DLL without a manual environment variable.
- Runtime DLL discovery checks app-local vendor locations before falling back to PATH/Program Files locations.
- OfficeWhere still does not bundle or install `Everything.exe`; Everything must already be installed and running for SDK-accelerated discovery.
- Bundled DLL license notice is stored at `backend/vendor/everything/LICENSE.txt`.

## Version

- Frontend package and backend API version: `0.14.0`.

## Verification checklist

- `./venv/bin/python -m pytest -q`
- `cd frontend && npm run build:electron && npm run build`
- `./venv/bin/python -m compileall backend backend_server.py -q`
- `./venv/bin/python scripts/run_demo_checks.py`
- `git diff --check`
