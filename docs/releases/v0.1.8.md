# OfficeWhere v0.1.8 Release Notes

## Highlights

- Renamed the former history screen to **Version Management** / **버전 관리**.
- Search results for Excel now show the real worksheet coordinate, for example `Sheet1 | 5행 E열`, instead of using the detected table header as the column label.
- Excel version details are simpler:
  - value differences show only file, real cell location, and value;
  - row additions/deletions show the row contents in a horizontally scrollable preview;
  - column additions/deletions are shown as simple column-added/removed messages.
- Version groups can now be opened and closed with the same button.
- Word diffs use solid red/green diff backgrounds so deleted and added content is easier to scan.

## Verification

- Backend test suite: `./venv/bin/python -m pytest`
- Frontend build: `cd frontend && npm run build`
- Static checks: `git diff --check`, `./venv/bin/python -m compileall -q backend`
