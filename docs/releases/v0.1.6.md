# OfficeWhere v0.1.6 Release Notes

## Highlights

- Reworked the **Version grouping / Consistency** screen around auto-detected Office document groups instead of manual full-list selection.
- Added on-demand group timelines with latest-candidate ordering, path/timestamp context, and open-file actions.
- Added direct compare actions:
  - Word/PowerPoint: compare the latest two files.
  - Excel: compare the latest two files, the whole detected group when it fits the detail cap, or the latest 200 files for very large groups.
- Added lightweight file-level content fingerprints to support evidence-based “same content” / “content differs” labels.
- Kept paragraph/cell/slide-level fingerprint storage deferred because it can add hundreds of MB to 1GB+ on large libraries.

## User-visible behavior

- The consistency screen now starts with summary cards and bounded group pages.
- Manual file selection is still available, but it is collapsed behind an advanced section.
- Content difference wording appears only when fingerprint evidence exists.
- Text and Markdown files remain searchable but are excluded from Office consistency/version groups.

## Verification

- Backend test suite: `./venv/bin/python -m pytest`
- Frontend build: `cd frontend && npm run build`
- Static checks: `git diff --check`, `./venv/bin/python -m compileall -q backend`
