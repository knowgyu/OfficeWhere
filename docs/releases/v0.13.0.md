# OfficeWhere v0.13.0 release notes

## Manual refresh flow

- Adding a watched folder now only saves the target list. It no longer starts an immediate document refresh.
- The UI tells users to press “문서 새로고침” after adding or changing a target folder, so slow initial scans do not surprise users while they are still editing settings.

## Optional Everything discovery accelerator

- On Windows, document refresh can use the Everything SDK DLL (`Everything64.dll` or `Everything32.dll`) as a fast discovery provider when Everything is installed and running.
- Everything discovery is optional. If the SDK DLL is missing, IPC is unavailable, the app is not running on Windows, or Everything returns no results, OfficeWhere falls back to the existing read-only filesystem scan.
- Refresh progress and completion responses now expose `discovery_source`, `discovery_hint`, and `discovery_help_url` so the UI can show friendly setup guidance instead of failing silently.
- Everything results are treated as an acceleration hint, not proof that missing files were deleted. OfficeWhere does not mark source documents as missing from an Everything-only absence.
