# OfficeWhere v0.7.5

## 변경 사항

- GitHub Actions 릴리스 빌드에 macOS Apple Silicon 패키징을 추가했습니다.
- 태그를 push하면 Windows x64 zip과 macOS arm64 dmg/zip 산출물을 함께 GitHub Release에 게시합니다.
- macOS runtime 준비 단계는 GitHub API를 인증된 요청으로 조회해 릴리스 빌더에서 asset 선택이 안정적으로 동작하도록 했습니다.
- macOS 패키지는 기존 Python backend를 재사용하기 위해 private Python runtime을 앱 안에 포함합니다. 사용자 PC에 Python을 별도로 설치할 필요는 없습니다.
- 다운로드/직접 빌드 문서에서 macOS 패키지를 더 이상 “추후 지원”으로 안내하지 않도록 정리했습니다.

## 참고

- Windows와 macOS 모두 사용자가 Python을 별도로 설치하지 않아도 실행되도록 private Python runtime을 포함합니다.
- macOS는 현재 OfficeWhere의 검색·색인·비교 backend를 그대로 재사용하는 최소 변경 릴리스 경로로 private Python runtime을 포함합니다.
- Linux packaged release는 아직 제공하지 않습니다.
