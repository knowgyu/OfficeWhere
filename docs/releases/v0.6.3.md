# OfficeWhere v0.6.3

Excel 문서가 여러 시트로 구성된 실사용 파일을 제대로 검색·버전비교할 수 있도록 전체 표시 시트 인덱싱을 도입한 패치입니다. 이 문서는 릴리즈 노트 초안이며, 태그와 GitHub Release는 별도로 만들지 않습니다.

## 변경 사항

- Excel 색인 시 첫 시트만 보던 경로를 전체 표시 시트 기준으로 확장했습니다.
- 검색 색인에는 `시트명 · 행 · 열` 위치가 함께 저장되어 두 번째 이후 시트의 셀도 검색됩니다.
- 버전관리 비교는 색인 시 저장한 시트/셀 캐시가 원본 파일 mtime과 맞으면 DB 캐시를 우선 사용하고, 캐시가 없거나 파일이 바뀐 경우에만 원본을 다시 읽습니다.
- 숨김/veryHidden `.xlsx` 시트는 기본 검색·비교 대상에서 제외해 사용자가 보는 시트 중심으로 동작합니다. 레거시 `.xls`는 현재 경량 파서 경로에서 제공되는 시트 목록을 사용합니다.
- Excel 비교 캐시 버전을 올려 이전 첫-시트 기준 비교 결과가 재사용되지 않도록 했습니다.
- 0.6.3으로 앱/백엔드 버전 메타데이터를 올렸습니다.

## 업데이트 후 참고

- 이 변경이 들어간 첫 실행에서는 기존 Excel 색인이 전체 시트 기준이 아니므로 앱 소유 색인 캐시가 무효화됩니다.
- 원본 Office 문서는 수정·삭제하지 않으며, 대상 폴더 재스캔/재색인 후 전체 시트 검색·비교 캐시가 채워집니다.
