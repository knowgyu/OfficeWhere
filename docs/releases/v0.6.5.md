# OfficeWhere v0.6.5

버전관리 비교 화면의 체감 속도를 줄이고, 다음 리팩터링을 안전하게 이어가기 위해 내부 책임 경계를 정리한 패치입니다.

## 변경 사항

- Excel 버전 비교가 빈 셀 전체를 훑는 방식에서 값이 있는 좌표 중심의 sparse diff 방식으로 개선되었습니다.
- 변경점이 많거나 일부만 표시되는 비교 결과에는 참고 안내를 표시해, 같은 버전이 아닐 수 있는 경우를 사용자가 더 빨리 알아차릴 수 있게 했습니다.
- Word/PPT 비교는 색인 시점에 만든 압축 비교 artifact를 우선 사용해, 비교 시 원본 문서를 다시 여는 일을 줄였습니다.
- PPT 비교에 계산량 guard를 추가해 큰 슬라이드 덱에서 과도하게 느려지는 상황을 완화했습니다.
- 버전 그룹 목록은 SQL summary/filter/sort/page 흐름을 사용해, 목록 조회 시 전체 `group_json`을 매번 크게 훑지 않도록 정리했습니다.
- `library.py`의 파일명 identity, 라이브러리 설정, 폴더 스캔 책임을 별도 모듈로 분리했습니다.
- `ConsistencyCheck.tsx`의 비교 결과 view를 `frontend/src/components/consistency/` 하위 컴포넌트로 분리했습니다.
- 앱 패키지 버전을 `0.6.5`로 올렸습니다.

## 메모

- Everything/ES 연동은 이번 릴리즈에 포함하지 않았습니다. 다음 작업 후보로 남겨둡니다.
- DB 교체, API client 분리, group-index/rescan 2차 구조 분리는 이번 릴리즈 범위가 아닙니다.
- 원본 Office 문서는 계속 읽기 전용으로만 다룹니다.

## 테스트

- `./venv/bin/python -m pytest -q`
- `./venv/bin/python scripts/run_demo_checks.py`
- `./venv/bin/python -m compileall backend backend_server.py -q`
- `cd frontend && npm run build`
- `cd frontend && npm run build:electron`
- `git diff --check`
