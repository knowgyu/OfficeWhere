# OfficeWhere v0.15.1

검색 결과 더보기 동작과 검색 성능 진단 로그를 다듬은 패치 릴리즈입니다.

## 수정 사항

- 빠른 검색 팔레트나 외부 `openSearch` 요청으로 메인 검색 탭을 연 뒤, 하단에서 더보기를 불러올 때 같은 검색 요청이 다시 실행되어 첫 20개 결과로 되돌아가던 문제를 수정했습니다.
- 같은 외부 검색 요청은 nonce 기준으로 한 번만 소비하도록 해, 무한 스크롤 결과가 기존 결과에 이어 붙도록 했습니다.

## 진단 개선

- 검색 성능 로그에 SQLite DB open 시간(`db_open_ms`)과 검색 인덱스 상태 조회 시간(`search_index_status_ms`)을 추가했습니다.
- 본문 검색 경로에서 FTS rowid 조회, rowid 필터링, 파일별 FTS 조회, 상세 chunk fetch, snippet 생성 시간을 각각 기록합니다.
- 회사 EDR/백신 환경에서 병목이 DB open인지, 첫 DB read인지, FTS table read 자체인지 구분할 수 있게 했습니다.

## 안전성

- API 요청/응답 형식은 변경하지 않았습니다.
- 원본 Office 문서는 계속 읽기 전용으로만 처리합니다.
- 이번 패치는 진단 로그와 검색 UI 상태 처리에 한정됩니다.

## 검증

- 검색 더보기 회귀 테스트에 외부 launch 검색 후 무한 스크롤 append가 유지되는 케이스를 추가했습니다.
- 검색 성능 로그 회귀 테스트에 DB open 및 FTS read 세부 timing 필드를 추가했습니다.
- 백엔드 검색 회귀 테스트, 프론트엔드 테스트, 빌드, Electron TypeScript 빌드를 통과했습니다.
