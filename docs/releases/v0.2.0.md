# OfficeWhere v0.2.0

## 사용자에게 보이는 변경
- 창의 X 버튼을 눌렀을 때 **백그라운드 실행 / 앱 종료 / 취소**를 고를 수 있고, 선택을 기억하면 이후에는 설정에서 다시 바꿀 수 있습니다.
- 백그라운드 실행 시 OfficeWhere가 트레이에 남아 자동 색인을 계속할 수 있으며, 트레이 메뉴에서 다시 열거나 종료할 수 있습니다.
- 앱 데이터 초기화는 더 이상 재시작을 시도하지 않고, 삭제 후 앱을 명확히 종료하도록 바뀌었습니다.
- 설정 화면에 전역 글자 크기와 창 닫기 동작을 함께 배치해 테스트/운영 환경에서 조정하기 쉽게 했습니다.
- Excel 버전 관리의 상세 정보는 기본 접힘 상태로 정리했고, `값 다름` 표현을 `값 변경`으로 바꿨습니다.
- Excel `표로 보기` 모달을 화면에 더 크게 띄우고, 표 영역의 둥근 모서리/여백을 줄여 실제 셀을 더 넓게 볼 수 있게 했습니다.
- Word/PPT의 기존 내용과 변경 후 내용 패널 테두리를 더 두껍게 표시해 비교 영역이 잘 보이도록 했습니다.

## 확인 포인트
- X 버튼 첫 클릭에서 묻기 창이 뜨고, “이 선택 기억하기” 후 설정의 `창 닫기 동작` 값이 반영되는지 확인하세요.
- 트레이에 남긴 뒤 트레이 메뉴의 `OfficeWhere 열기`와 `종료`가 동작하는지 확인하세요.
- 앱 데이터 초기화 후 프로세스가 재시작되지 않고 종료되는지 확인하세요.
- Excel 버전 관리에서 `표로 보기`가 큰 모달로 열리고 가로/세로 스크롤이 가능한지 확인하세요.
