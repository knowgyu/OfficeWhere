# OfficeWhere v0.1.11 Release Notes

## What changed

- Added an Excel **표로 보기** flow in Version Management.
- Excel version groups can now open a large in-app modal that renders the latest file as an Excel-like grid.
- Changed cells are highlighted:
  - green: added value/content;
  - red: removed value/content;
  - yellow: changed value.
- Hovering a highlighted cell shows a quick before/after summary.
- Clicking a highlighted cell pins detailed per-version transition history when adjacent comparison results are available.
- Large Excel sheets render bounded sections instead of the full sheet:
  - small sheets show the full table;
  - medium sheets can show from the top-left through the changed area;
  - far-apart changes are split into multiple sections;
  - huge sheets show local ranges around changes plus the key column where possible.
- The modal supports vertical scrolling, horizontal scrolling, and Shift + mouse wheel horizontal scrolling.

## Notes

- The grid is latest-file based; deleted rows/columns that no longer exist in the latest file may be summarized in existing change cards rather than shown as physical latest-grid cells.
- This is not a pixel-perfect Excel renderer. It is a comparison-focused table view that keeps source files read-only.
