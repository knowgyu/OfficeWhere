# OfficeWhere v0.7.13

## 달라진 점

- 검색 빈 화면에서 바로 대상 폴더를 추가할 수 있게 하고, 검색 대상 확인 흐름이 폴더 입력칸으로 바로 이어지도록 다듬었습니다.
- 검색 결과 안의 중복 문서 이동 버튼은 제거하고, 같은 내용 문서는 전용 탭에서 확인하도록 행동 경로를 단순화했습니다.
- 튜토리얼과 변경 이력 화면의 문구를 `변경 내용`, `바뀐 셀`, `시트로 보기` 중심으로 정리해 Excel 안내가 더 자연스럽게 이어지도록 했습니다.
- 변경 이력, 같은 내용 문서, 표시 설정 주변 문구를 함께 다듬어 화면 간 표현을 맞췄습니다.
- README를 짧은 랜딩 문서로 다시 구성하고, 제품 흐름을 한눈에 볼 수 있는 SVG 개요 이미지를 추가했습니다.
- Vitest/RTL/MSW 기반 프론트엔드 단위·컴포넌트 테스트와 Playwright Electron E2E 스펙을 보강했습니다.
- 프론트엔드 테스트 워크플로와 E2E TypeScript 검증을 CI에 맞춰 정리했습니다.
