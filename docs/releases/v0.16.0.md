# OfficeWhere v0.16.0

패키징을 가볍게 만들고 frontend/backend의 불필요한 의존·죽은 코드를 줄인 릴리즈입니다.

## 패키징

- Windows Python runtime을 repo에 vendoring하지 않고 Windows packaging 단계에서 생성합니다.
- `npm run package:win`은 공식 Python embeddable zip과 `requirements.txt` 패키지를 준비한 뒤 Electron zip에 포함합니다.
- 사용자는 기존처럼 Python이나 pip 설치 없이 Windows zip의 `OfficeWhere.exe`만 실행하면 됩니다.
- macOS runtime도 같은 생성형 staging 정책을 문서화했습니다.

## 의존성 정리

- frontend API client에서 Axios를 제거하고 native `fetch` wrapper를 사용합니다.
- 기존 UI/tests가 기대하는 `{ data }` 성공 응답과 `{ response: { status, data } }` 오류 형태는 유지했습니다.

## 코드 정리

- 참조되지 않는 backend helper와 legacy PowerPoint parser 경로를 삭제했습니다.
- PowerPoint 본문/표 읽기는 runtime에서 `python-pptx`가 아니라 기존 OOXML zip parser 경로를 사용합니다.
- 원본 Office 문서는 계속 읽기 전용으로만 처리합니다.

## 검증

- `./venv/bin/python -m pytest -q`
- `./venv/bin/python -m compileall backend backend_server.py scripts/prepare_python_runtime.py -q`

- `cd frontend && npm run build:electron`
- `cd frontend && npm run test:run`
- `./venv/bin/python scripts/prepare_python_runtime.py mac-arm64 --dry-run`
- `./venv/bin/python scripts/prepare_python_runtime.py win-x64 --dry-run`
- `git diff --check`
