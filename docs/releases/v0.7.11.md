# OfficeWhere v0.7.11

## 달라진 점

- 튜토리얼 강조 표시가 화면 밖 대상이나 빈 영역에 남지 않도록 정리했습니다.
- 튜토리얼 화면 전체 딤 처리를 제거하고, 필요한 대상만 차분하게 강조하도록 바꿨습니다.
- Excel 변경점 안내가 너무 빨리 넘어가지 않도록 확인 시간을 늘렸습니다.
- Excel `표로 보기` 모달은 좁은 창에서도 좌우 여백과 셀 폭이 더 자연스럽게 보이도록 조정했습니다.
- 기본 앱 창 크기를 조금 키워 검색, 이력, 중복 파일 화면을 더 넓게 볼 수 있게 했습니다.
- 라이트/다크 테마의 표면색, 경계선, 변경점 색상 대비를 다듬었습니다.
- 릴리스 빌드에서 백엔드 검증을 단일 캐시 job으로 분리해 Windows/macOS 패키징 job의 반복 설치와 반복 테스트를 줄였습니다.

## 확인한 항목

- Frontend build
- Electron main-process build
- Backend/unit tests
- Python compile check
- Release workflow YAML parse
- Git whitespace check
