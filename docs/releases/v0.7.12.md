# OfficeWhere v0.7.12

## 달라진 점

- 앱 전반의 라이트/다크 톤을 더 차분한 문서 작업용 데스크톱 콘솔에 맞게 정리했습니다.
- 온보딩 화면을 어두운 홍보 화면처럼 보이지 않도록 바꾸고, 설명 문구를 더 자연스러운 한국어로 다듬었습니다.
- 튜토리얼에서 별도 조작이 필요 없는 본문 매칭 단계를 줄이고, “일정” 검색 결과를 확인한 뒤 여유 있게 다음 안내로 이어지도록 했습니다.
- 튜토리얼 강조 표시가 화면 밖 대상에 남지 않도록 가시성 판단을 보강하고, 과한 딤·글로우·반짝임을 줄였습니다.
- 검색, 변경 이력, 같은 내용 문서 화면의 요약 영역과 카드 톤을 맞춰 화면 간 이질감을 줄였습니다.
- 같은 내용 문서 조회 로직을 별도 storage seam으로 분리해 `database.py`의 책임을 조금 줄였습니다.
