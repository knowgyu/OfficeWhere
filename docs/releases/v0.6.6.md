# OfficeWhere v0.6.6

v0.6.5 릴리즈 빌드에서 드러난 Windows CI 회귀를 고치고, v0.6.5에 포함하려던 버전관리 성능 개선과 책임 분리 변경을 다시 묶은 패치입니다.

## 변경 사항

- 비교 artifact DB가 아직 없거나 열 수 없는 환경에서도 Word/PPT 비교가 원본 파싱 fallback으로 정상 진행되도록 수정했습니다.
- artifact DB unavailable fallback 회귀 테스트를 추가했습니다.
- Excel 버전 비교는 값이 있는 좌표 중심의 sparse diff 방식으로 개선되어 큰 빈 영역을 불필요하게 훑는 일을 줄였습니다.
- 변경점이 많거나 일부만 표시되는 비교 결과에는 참고 안내를 표시합니다.
- Word/PPT 비교는 색인 시점에 만든 압축 비교 artifact를 우선 사용해 원본 문서 재읽기를 줄입니다.
- PPT 비교에 계산량 guard를 추가해 큰 슬라이드 덱에서 과도하게 느려지는 상황을 완화했습니다.
- 버전 그룹 목록은 SQL summary/filter/sort/page 흐름을 사용합니다.
- `library.py`의 파일명 identity, 라이브러리 설정, 폴더 스캔 책임을 별도 모듈로 분리했습니다.
- `ConsistencyCheck.tsx`의 비교 결과 view를 `frontend/src/components/consistency/` 하위 컴포넌트로 분리했습니다.
- 앱 패키지 버전을 `0.6.6`으로 올렸습니다.

## 메모

- `v0.6.5` 태그는 Windows 릴리즈 빌드의 backend test 단계에서 실패했습니다. 실제 릴리즈 아티팩트는 `v0.6.6`을 기준으로 사용하세요.
- Everything/ES 연동, API client 분리, group-index/rescan 2차 구조 분리는 이번 릴리즈 범위가 아닙니다.
- 원본 Office 문서는 계속 읽기 전용으로만 다룹니다.

## 테스트

- `./venv/bin/python -m pytest -q`
- `./venv/bin/python scripts/run_demo_checks.py`
- `./venv/bin/python -m compileall backend backend_server.py -q`
- `cd frontend && npm run build`
- `cd frontend && npm run build:electron`
- `git diff --check`
