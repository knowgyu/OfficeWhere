# OfficeWhere v0.2.1

## 사용자에게 보이는 변경
- Excel 버전 관리의 `표로 보기`가 비교 대상 파일들의 전체 사용 범위와 여유 2행/2열을 기준으로 표시됩니다. 변경점 목록이 많아 일부가 잘려도 먼 위치의 추가/삭제/변경 셀을 놓치지 않도록 보강했습니다.
- Excel 표로 보기에서 긴 셀 값이 열 폭을 과하게 늘리지 않도록 고정 폭을 적용하고, 열 머리글을 `A`, `B`, `C`처럼 단순하게 정리했습니다.
- Excel 표로 보기의 A열/헤더 고정을 제거해 가로 스크롤 시 표 전체가 자연스럽게 이동합니다.
- 변경 셀 상세는 표 아래에 바로 이어서 표시되고, 별도 내부 스크롤 없이 모든 이력을 페이지 흐름대로 볼 수 있습니다.
- 변경 이력 값은 `A → B` 대신 `수정 전` / `수정 후` 박스로 나눠 표시해, 셀 값에 화살표가 포함되어도 혼동이 없도록 했습니다.
- Excel 버전 관리와 검색/색인은 저장된 Excel 통합용 표 범위가 오래되어도 원본 시트의 실제 사용 범위를 읽어 동작합니다.
- 예제 생성 스크립트가 Word/PPT/Excel v1~v4 샘플과 실제 사례형 테스트 라이브러리를 생성합니다.

## 확인 포인트
- Excel 버전 그룹에서 `표로 보기`를 열었을 때 v1이 47행 AH열까지 사용되는 예제는 49행 AJ열까지 표시되는지 확인하세요.
- 표의 추가/삭제/변경 셀 색상이 유지되고, 셀 클릭 시 모든 버전 이력이 `수정 전` / `수정 후` 박스로 표시되는지 확인하세요.
- Shift + 마우스 휠 가로 스크롤이 동작하고 개발자 도구에 passive wheel 경고가 뜨지 않는지 확인하세요.
- 오래된 Excel `parser_config`가 있어도 검색/버전 관리/재스캔에서 범위 오류가 뜨지 않는지 확인하세요.
- `python scripts/generate_demo_cases.py` 실행 후 `examples/officewhere_test_library`에서 `사업예산`, `주간보고`, `프로젝트상태`가 v4까지 생성되는지 확인하세요.
