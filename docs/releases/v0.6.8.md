# OfficeWhere v0.6.8

## 요약

문서 새로고침의 파일 발견 단계를 더 가볍게 만든 성능/안정화 릴리즈입니다. v0.6.7 이후의 내부 책임 경계 정리도 함께 포함합니다.

## 주요 변경

- 등록 파일 목록 UI와 버전 그룹 저장 로직을 안정적인 facade 뒤로 분리한 후속 리팩터링을 포함했습니다.
- 대상 폴더 스캔을 `os.scandir` 기반 스트리밍 탐색으로 바꿔 큰 폴더에서 파일 발견 단계의 오버헤드를 줄였습니다.
- 반복 새로고침에서 안전하다고 확인된 디렉토리 snapshot을 재사용하는 보수적 캐시를 추가했습니다.
- 캐시가 없거나 오래됐거나, 디렉토리 상태가 바뀌었거나, 네트워크/UNC처럼 신뢰도가 낮은 경로라면 전체 스캔으로 되돌아갑니다.
- 수동 폴더 스캔과 라이브러리 새로고침이 같은 파일 필터링 규칙을 쓰도록 정리했습니다.

## 검증

- 이 릴리즈 준비 작업은 scanner cache/fallback 회귀 테스트와 기존 새로고침 테스트를 포함합니다.
- Everything 연동은 이 버전에 포함하지 않습니다. Everything은 별도 v0.7.0 후보 작업이며, 일반/Lite/미설치 Windows 수동 검증 뒤에만 릴리즈할 예정입니다.
