# OfficeWhere v0.14.3 release notes

## What changed

- File type chips now use compact extension-style labels: `DOCX`, `XLSX`, `PPTX`, `PDF`, with `MD`/`TXT`/`FILE` fallbacks.
- The shared file type chip now has a fixed width and centered label, so search results, file lists, duplicate views, and consistency/check surfaces align more consistently.

## Notes

- This is a UI presentation-only patch. It does not change file parsing, indexing, search ranking, rescan behavior, or source documents.
- Frontend package and backend API version: `0.14.3`.
