# OfficeWhere v0.7.0

## 요약

완성된 문서 찾기, 검색, 색인, 버전 비교 흐름에 집중하기 위해 미완성 엑셀 통합/결합 표면과 Everything 연동 후보를 정리한 안정화 릴리즈입니다.

## 주요 변경

- 엑셀 통합/결합, 표 등록 후보, 키 컬럼 추천처럼 사용자가 실제 기능으로 쓰기 어려웠던 미완성 화면과 API 계약을 제거했습니다.
- 라이브러리 그룹 결과에서 내부 판단용 권장 액션 힌트를 제거해 사용자에게 필요한 그룹, 대표 문서, 차이 정보만 남겼습니다.
- 엑셀 검색, 색인, 버전 비교, “표로 보기” 흐름은 파일을 수정하지 않는 source-coordinate used-range 기반으로 유지했습니다.
- 과거 앱 데이터에 남아 있을 수 있는 통합/추천 액션 흔적은 앱 소유 DB/index/cache 재생성으로 정리되며, 원본 문서는 삭제하거나 수정하지 않습니다.
- Everything/ES 가속은 설치/진단 부담 대비 이득이 파일 발견 일부에 제한되어 현재 릴리즈 후보에서 제외했습니다. 기본 스캐너와 snapshot cache/fallback 경로를 유지합니다.

## 검증

- Python backend compile/test, frontend TypeScript/Vite/Electron build, demo document smoke check, whitespace check로 검증합니다.
- Windows/macOS 패키지 설치 후 수동 실행 검증은 배포 아티팩트 생성 단계에서 별도로 확인합니다.
