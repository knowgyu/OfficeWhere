# OfficeWhere v0.1.10 Release Notes

## What changed

- Moved text-size control from the Version Management page to **Settings / Library → 화면 표시** so it applies across the whole app.
- Added a larger **아주 크게** text-size option. The global shortcuts `Ctrl +`, `Ctrl -`, `Ctrl + mouse wheel`, and `Ctrl + 0` now adjust/reset the app-wide text size.
- Improved Version Management opening behavior: when a different group is opened, the app scrolls the selected group back into view so the user does not lose context after the previous group collapses.
- Reworked Excel version differences around user-visible content changes:
  - clear cell-level value differences still appear under **값 다름**;
  - blank-to-value / value-to-blank cells are now reported as **내용 추가** / **내용 삭제**;
  - rows or columns that only exist in one file are shown under **추가/삭제된 내용** with an actual content preview instead of a vague structure-only status.
- Added one-command web testing scripts:
  - macOS/Linux: `BACKEND_PORT=8876 FRONTEND_PORT=5174 ./dev-web.sh`;
  - Windows: `dev-web.bat -BackendPort 8876 -FrontendPort 5174`.

## Notes

- Excel row/column-only differences are still not interpreted as semantic “new features.” The UI now shows the actual added/removed values first and treats the row/column shape as supporting location information.
- For very large added/removed Excel columns, the preview is capped to the first 25 displayed rows while still showing the total detected count.
- GitHub Release automation still publishes Windows zip only. macOS desktop packaging needs a separate mac target/build/signing path, while browser-based web testing works on macOS with Python and Node installed.
