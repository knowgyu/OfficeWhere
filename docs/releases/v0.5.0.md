# OfficeWhere v0.5.0

## 사용자에게 보이는 변경
- 버전 관리에서 기본 비교를 `이전 버전 → 최신 버전` 한 쌍으로 정리했습니다. 필요한 경우 파일 목록의 `1`/`2` 표시를 눌러 원하는 두 버전만 골라 비교할 수 있습니다.
- 버전 파일 목록은 최근 수정된 5개만 먼저 보여주고, 필요할 때 `모두 보기`로 펼칠 수 있습니다.
- 비교 중인 두 파일명 옆에 각각 `열기` 버튼을 붙여 긴 변경 내역을 보다가도 바로 원본 파일을 열 수 있습니다.
- `본문 부족`, `일부만 확인` 같은 내부 진단 태그는 버전 카드에서 숨겨 사용자에게 필요한 그룹/파일 정보만 남겼습니다.
- PPT 변경 내역은 슬라이드별로 접힌 상태에서 시작합니다. 긴 텍스트 변경은 일부만 먼저 보여주고 `전체 보기`로 펼칠 수 있습니다.
- 좁은 창에서 변경 전/후 내용이 세로로 쌓이면, 창을 넓히면 더 보기 편하다는 안내를 표시합니다.

## 성능/동작 변경
- 버전 관리에서 모든 인접 버전을 한꺼번에 비교하지 않고 현재 선택된 두 파일만 계산합니다. 버전이 많은 묶음에서 처음 열 때의 부담과 화면 길이를 줄였습니다.
- Excel `표로 보기`는 현재 선택된 비교 쌍의 변경 초점을 기준으로 표시합니다.

## 확인 포인트
- 버전 파일이 6개 이상인 묶음에서 처음에는 5개만 보이고, `모두 보기`/`최근 5개만 보기`가 동작하는지 확인하세요.
- 기본 선택이 `1=이전`, `2=최신`인지, 다른 파일의 `1`/`2` 버튼을 눌렀을 때 해당 두 파일만 다시 계산되는지 확인하세요.
- Word/PPT 버전 비교에서 각 파일명 옆 `열기` 버튼이 원본 파일을 여는지 확인하세요.
- PPT 변경 내역이 슬라이드별로 접혀 있고, `자세히 보기`와 긴 텍스트 `전체 보기`가 자연스럽게 동작하는지 확인하세요.
- 좁은 창에서 변경 전/후 내용이 1열로 보일 때 안내 문구가 표시되는지 확인하세요.
