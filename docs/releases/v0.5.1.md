# OfficeWhere v0.5.1

튜토리얼의 이동 흐름을 더 자연스럽게 다듬은 패치 릴리스입니다.

## 변경 사항

- 예제 폴더 추가 후 `문서 새로고침`을 직접 눌러 새 파일/수정 파일 재색인 흐름을 확인하도록 안내했습니다.
- PPT 버전 진단에서 `자세히 보기`를 먼저 눌러 실제 변경 내용을 확인하도록 튜토리얼 단계를 나눴습니다.
- Excel 버전 진단은 검색창에서 `사업예산`을 찾은 뒤 결과를 열도록 바꿔 갑작스러운 자동 이동을 줄였습니다.
- Excel 표로 보기에서는 D7 셀 선택과 하단 셀 변경 이력 확인까지 이어지는 안내를 추가했습니다.
- 튜토리얼 완료 후 약 3초 뒤 안내가 자동으로 닫히도록 했습니다.

## 테스트

- `cd frontend && npm run build`
- `cd frontend && npm run build:electron`
- `./venv/bin/python -m pytest -q`
- `./venv/bin/python scripts/run_demo_checks.py`
- `./venv/bin/python -m compileall backend backend_server.py -q`
- `git diff --check`
