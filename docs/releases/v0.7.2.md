# OfficeWhere v0.7.2

## 변경 사항

- 앱 내 업데이트 동작을 포터블 배포 방식에 맞게 단순화했습니다.
- 기존처럼 실행 중인 OfficeWhere 폴더를 자동 교체하지 않고, **zip 다운로드** 버튼으로 GitHub Release의 Windows zip을 다운로드 폴더에 저장합니다.
- 다운로드한 zip은 함께 게시된 SHA256 파일로 검증한 뒤 파일 위치를 엽니다.
- 이미 같은 zip을 받아 둔 경우에는 다시 받지 않고 기존 파일을 확인합니다.
- 원본 문서와 앱 데이터는 업데이트 zip 다운로드 과정에서 수정하거나 삭제하지 않습니다.

## 사용 방법

1. 업데이트 알림에서 **zip 다운로드**를 누릅니다.
2. 다운로드 폴더에 저장된 `officewhere-v0.7.2-windows-x64.zip`의 위치가 열립니다.
3. zip을 원하는 위치에 압축 해제한 뒤 새 `OfficeWhere.exe`를 실행합니다.

## 참고

- v0.7.0/v0.7.1에 들어 있던 포터블 폴더 셀프교체 방식은 Windows 설치 위치와 권한에 따라 실패할 수 있어 제거했습니다.
- v0.7.0에서 바로 이 새 다운로드 방식이 소급 적용되지는 않습니다. v0.7.2를 한 번 수동으로 받아 실행한 뒤부터 이후 업데이트 알림은 zip 다운로드 방식으로 동작합니다.
