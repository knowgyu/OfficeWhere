# Local font assets

Packaged Electron builds load these fonts from the renderer bundle so app-data/cache resets and offline use do not leave Material Symbols icons as plain ligature text.

- `material-symbols-rounded.ttf`: Google Material Symbols Rounded, fetched from Google Fonts.
- `pretendard-variable.woff2`: Pretendard Variable v1.3.9, fetched from the Pretendard jsDelivr/GitHub package.
- `jetbrains-mono-400.ttf`, `jetbrains-mono-500.ttf`: JetBrains Mono weights used by the UI, fetched from Google Fonts.
